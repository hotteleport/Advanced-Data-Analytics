# Advanced Data Analytics

University coursework on preparing data for machine learning. It uses two datasets: pet food customer orders (classification, predicting an active subscription) and ship fuel efficiency (regression, predicting fuel consumption).

## Contents

| Folder | Topic | Methods and tools |
|---|---|---|
| `ex.1` | Evaluating dataset quality | Data cleaning, ydata-profiling, Sweetviz, AutoViz, DataPrep, D-Tale, Phik, Yellowbrick |
| `ex.2` | Distribution optimization | SMOTE, Isolation Forest, IQR and z-score filtering, log1p transformation, synthetic data with SDV, model comparison |
| `ex.3` | Feature selection and generation | SelectKBest, correlation matrix, VIF, interaction features, model evaluation |

Start with the final report in each folder:

- [Dataset quality](ex.1/Final_Report_Evaluating_dataset_quality.ipynb)
- [Distribution optimization](ex.2/Final_Report_Distribution_Optimization.ipynb)
- [Feature selection](ex.3/Final_Report_Feature_Selection.ipynb)
